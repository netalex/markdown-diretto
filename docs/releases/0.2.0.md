# Markdown Diretto 0.2.0 — Alpha

Scrivi Markdown nelle email e mostra formattato il Markdown grezzo dei messaggi ricevuti.

## Novità

- Pulsante dedicato alla lettura: **Mostra Markdown formattato** e **Mostra originale**.
- Ripristino del documento originale senza modificare l’email salvata.
- Correzione della dipendenza da `crypto.randomUUID` introdotta nella 0.1.1.
- 19 test JavaScript e 4 test packaging passati nell’ambiente di sviluppo.

## Installazione

Installa l’asset `markdown-diretto-0.2.0.xpi` da **Componenti aggiuntivi e temi → ingranaggio → Installa componente aggiuntivo da file**.

Gli archivi “Source code” non sono installabili. L’aggiornamento richiede il permesso aggiuntivo sui messaggi visualizzati. Riavvia Thunderbird dopo l’installazione.

## Stato

Conversione e ripristino in composizione confermati dall’utente su Thunderbird 155.0.1 Windows 64 bit. La modalità lettura resta da confermare sul client. Versione preliminare: il sorgente Markdown della composizione non viene conservato tra riaperture delle bozze.
